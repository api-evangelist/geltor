# Geltor

Geltor is a biodesign company founded in 2015 by Alex Lorestani and Nick Ouzounov that
engineers animal-free designer proteins, peptides and polypeptides and manufactures them
through precision fermentation. Its Biodesigner AI computational biology platform is used
to imagine, screen and optimize novel protein sequences, which are then scaled commercially
as ingredients for beauty and personal care, specialty nutrition and medical/life-science
applications.

Portfolio: HumaColl 21 (biomimetic human collagen), HumaColl 21 Select (matrikine peptide
complex), Elastapure (biomimetic human elastin), Collume and Caviance (vegan collagens),
and PrimaColl — a Type XXI signaling collagen and the first biotech-derived collagen to
receive an FDA GRAS "no questions" letter for ingestible use.

- https://geltor.com/
- https://forgeglobal.com/geltor_stock/

## API surface

**Geltor publishes no public API.** Contract discovery (2026-08-01) probed `geltor.com` and
every plausible API host for OpenAPI/Swagger, GraphQL, MCP and A2A surfaces:

- `api.geltor.com`, `developer.geltor.com`, `docs.geltor.com`, `app.geltor.com`,
  `status.geltor.com`, `trust.geltor.com` — all NXDOMAIN.
- `portal.geltor.com` resolves to HubSpot marketing infrastructure (preference center);
  every probed path returns the HubSpot 404 catch-all.
- `/openapi.json`, `/swagger.json`, `/.well-known/*` on `geltor.com` — all 404.
- No first-party packages on npm, PyPI or RubyGems; no `geltor` GitHub organization.

The company sells business-to-business to brand formulators and manufacturers, so this is
an expected and honest result — not a gap.

## What the site does publish

- `llms.txt` (200) — a full site index generated by the All in One SEO WordPress plugin.
  Captured verbatim at `llms/geltor-llms.txt`.
- `robots.txt` (200) — explicitly **allows** GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot,
  Claude-User, Claude-SearchBot, anthropic-ai, Google-Extended, PerplexityBot,
  Perplexity-User, Applebot-Extended, CCBot and Amazonbot. A deliberate answer-engine
  posture, which is the only machine-readable agent surface Geltor operates.
